## 1.18.5 更新

- 「打开并验收」现在会把实际浏览器导航、原步骤交付说明和当前服务检查一起送审。验收通过后自动签收。
- 等待打开窗口的任务重启后仍可接续。连续发送「继续」只提示下一步，保留已通过的证据。
- 修复后台检查误标完成的问题。符合条件的未交付任务会恢复最后一步的待验收状态，并保留原始回执。

App 打开时持续执行目标，睡眠唤醒或重新打开后先核对上次结果再接续。
