## 1.16.0 更新

- 改善命令执行、工具链环境、超时和取消处理，支持在原会话查看及停止后台命令。
- 统一完全信任确认逻辑，减少已授权范围内的重复弹窗；保留明确的禁用、强制确认及权限保护。
- 修复编程草稿、检查、交付和任务验收的权限错配，以及技能更新、会话切换时的结果归属。
- 增强知识库真实分类匹配、原文归档、附件保留与写后核对，改善多轮确认和重试恢复。
- 修复安全设置在窄窗口及工具较多时的布局和分页。

后台状态限当前应用生命周期，进程已启动仍需核对服务是否可用；结果未知的写入不会自动重复执行。
