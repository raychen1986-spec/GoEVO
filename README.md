## 1.17.0 更新

- 同一目标跨执行片、资源等待、睡眠和应用重启接续，减少手动调整超时、次数和重复点击继续。
- 以真实端点和逐项证据核对交付；变更后只复验受影响成果，不重复已完成写入。
- 长命令按目标归属复用；暂停当前优化不会误停先前已验证交付的服务。
- 右栏聚焦目标、当前活动、里程碑和成果，支持完整记录与历史分页，完成后在原会话继续优化。
- 精简上下文和冷历史，汇总实际模型调用用量，区分排队/睡眠等待和工作时间；补齐安装、目录、工具回执及网页正文识别。

App 关闭期间不执行目标，重开后先核对再接续；结果未知的写入不会自动重复执行。真实权限、凭据、用户暂停/停止和明确投入约束继续生效。
