## 1.18.0 更新

- 同一对话可以先后完成多个目标。右侧工作台一次展示一项任务，可按标题或来源查找历史成果，随时返回当前任务。
- 任务先做必要的只读检查，再展示短计划。点击「确认并开始」后，按已批准的版本直接执行。App 重启后会恢复已保存的计划和批准状态。
- 交付后可以在普通对话直接问「这份说明里写了什么」。助手会读取对应的交付文件，回看历史时也能引用当时交付的文件。
- 小修改记录在原文件上，原验收问题在原目标中修复。新增模块可从已有成果派生新目标，独立支线也可以留在同一会话中。
- 打开网页时，GoEVO 浏览器会核实可见窗口、实际地址和页面内容，发生跳转时列出最终落点。页面连接失败时会在对话中说明原因。
- 任务规划与执行共用正常请求的模型和预算设置。任务聊天支持与普通对话一致的 Markdown 展示，服务等待、恢复和验收状态在工作台中分别呈现。

App 关闭期间不执行目标，重开后先核对再接续；结果未知的写入不会自动重复执行。真实权限、凭据、用户暂停/停止和明确投入约束继续生效。
